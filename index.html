Generate PHP 8+ type checking code for PHPStan PHPDoc types with @phpstan-assert-if-true. Source on GitHub.

Enter a type on the left and click Generate. Output tabs follow the pipeline left to right: Type AST → IR (build) → IR (optimized) → PHP Code. Some types cannot be validated at runtime (for example callable(int): void or unhandled generics) and report a generation error.

Warning: Always review generated PHP before using it in production. Output may be incorrect or incomplete for edge cases.
