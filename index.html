Generate PHP 8+ type checking code for PHPStan PHPDoc types with @phpstan-assert-if-true. Source on GitHub.

Enter a type and click Generate to produce PHP code. Use the output tabs to switch between the generated PHP Code and internally used Type AST. Some types cannot be validated at runtime (for example callable(int): void or unhandled generics) report a generation error.

Warning: Always review generated PHP before using it in production. Output may be incorrect or incomplete for edge cases.
