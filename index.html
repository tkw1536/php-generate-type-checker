PHP Type Checker Generator

Left: paste PHPStan type expressions (one or more) or a PHPDoc block starting with /*. Docblocks extract @phpstan-type aliases and generate one checker per alias. Options under the input control naming, optimization, alias handling, and PHP shape — hover each ? for details. Right: tabs follow the pipeline Type AST → IR (build) → IR (optimized) → PHP Code; output updates as you edit. Some types cannot be checked at runtime (for example callable signatures or unhandled generics) and report a generation error.

Type input

When on, checkers are named from the type (e.g. isPostListResponse). When off, they use check / check_1 / ….
When on, the IR optimizer runs before PHP is rendered for more compact output. When off, PHP is rendered from IR (build).
When on, @phpstan-type cross-references are inlined into each alias body. When off (default), they stay as named references and call the matching entry checker.
When on, re-emits the @phpstan-type definitions at the top of the generated PHP output.
Shape of the emitted PHP: top-level functions, or static methods with the chosen visibility.
