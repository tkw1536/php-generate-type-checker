Parse PHPStan PHPDoc types and generate PHP 8+ runtime checker methods with @phpstan-assert-if-true.

Use Generate PHP to emit a checkType(mixed $data): bool function or a static method inside TypeChecker. Use Parse AST to inspect the parsed type tree as JSON. Types that cannot be validated at runtime (for example callable(int): void or unhandled generics) report a generation error.
