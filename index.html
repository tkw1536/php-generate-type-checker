Generate PHP 8+ type checking code for PHPDoc types as supported by PHPStan with @phpstan-assert-if-true. Source on GitHub.

Edit the input or options on the left; output updates automatically. Paste type expressions (one or more) or a full PHPDoc block containing @phpstan-type aliases — when the input starts with /*, aliases are extracted, cross-references resolved, and one checker is generated per alias. Tabs follow the pipeline left to right: Type AST → IR (build) → IR (optimized) → PHP Code. With Optimize on, PHP uses IR (optimized); with it off, PHP is rendered from IR (build). Some types cannot be validated at runtime (for example callable(int): void or unhandled generics) and report a generation error.

Warning: Always review generated PHP before using it in production. Output may be incorrect or incomplete for edge cases.
